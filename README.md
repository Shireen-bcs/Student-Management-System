# 🎓 Student Management System

A simple Student Management System developed using Python. This is a menu-driven application that helps manage student records.

## 🚀 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student
- ✏️ Update Student
- ❌ Delete Student
- 🚪 Exit Program

## 🛠️ Technologies Used

- Python 3

## 📚 Python Concepts Used

- Variables
- Lists
- Dictionaries
- Loops (`while`, `for`)
- Conditional Statements (`if`, `elif`, `else`)
- User Input (`input()`)

## 📂 Project Structure

```
Student-Management-System/
│── student_management.py
└── README.md
```

## ▶️ How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Run:

```bash
py student_management.py
```

## 📸 Sample Output

```

1. Add Student

3. Search Student
4. Update Student
5. Delete Student
6. Exit
```

## 🎯 Purpose

This project was created to practice Python fundamentals and build a simple CRUD (Create, Read, Update, Delete) application for managing student records.
